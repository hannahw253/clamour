# Clamour

**For habitable homes.** A shared repair record for renters: one group per shared house, building or union branch, with dated evidence, legal clocks and letters.

This repository holds the Clamour web app. Work arrives as pull requests with a preview link from Vercel.

## Prototype

`/prototype` is a clickable prototype for interviews with renters, covering group set-up, invite links, logging a problem, the issue page with its legal clock, and letters. It stores everything in the browser and sends nothing anywhere. The code lives in `src/app/prototype` (screens) and `src/prototype` (data, clocks, components). Its clock rules follow the architecture north star's document 6.
